# Atlas 0.1.1 Physics polish audit

Patch version inspected from package.json and the live release: 0.1.0 → 0.1.1.
Scope: Home, sidebar behavior, Physics navigation/materials/walkthroughs, formal-report resources and the backend needed for private class sources and owner access. Chemistry, Biology and Japanese catalog records are unchanged. Stable assignment and question IDs are preserved.

## Product simplification

Home has compact College Heights / School District 57 / school-year/date context, a course list, an optional return link, and small factual details. It no longer repeats Calendar events. Winter-break countdown and completed student-day percentage use the approved SD57 calendar; 179 student days agree with its monthly totals. June 21 is an observance, not a student-day closure. Today is excluded from completed days. Source-code size is measured from nonblank TS/TSX/Astro/CSS/MJS lines under src, server and scripts at build time; generated content/data, dependencies, tests and documentation are excluded. Commit count appears only with complete local Git history. The current version comes from package.json.

Clicking atlas. animates and remembers sidebar collapse. Physics opens a simple unit list. Units separate Assignments, Notes and Labs. Assignment completion can be changed only on the assignment list. Assignment pages use breadcrumbs and retain the whole sheet, question navigation and Walk through. No Physics Todo filters, section-finished controls or Done on paper buttons remain. The focused teaching surface adapts to short desktop/phone screens; long content scrolls within it.

## Correctness and coverage

Every existing Physics checkpoint was audited: **115 total, 60 numerical walkthroughs and 55 written/packet question groups**. **24 written groups have a named source gap**; they are not represented as completed solutions. Multi-part reasoning includes staged calculations, distance versus displacement, average velocity, braking, vertical throws, travel to the apex, return times, and graph interpretation.

Right/up are positive unless the actual question defines an axis. Braking acceleration opposes velocity; it can therefore be positive for westward motion. Wadson’s supplied formula sheet specifies g = 9.8 m/s², so ordinary vertical examples use a = −9.8 m/s² with an explanation. Negative components are allowed in working, while final vector answers use magnitudes and explicit direction words. UI displacement uses Δd; stable internal Δx keys are retained. Rounding uses actual input precision, with addition/subtraction decimal-place rules distinguished from multiplication/division significant figures. Ambiguous tie rounding is identified; the handwritten round-even reminder is not claimed as a confirmed printed teacher rule.

Verified corrections include question 1’s 3.00 s, the dropped-log time 5.66 s, negative fall displacement/velocity, the falling square-root branch, westward braking with positive acceleration, the tectonic-drift acceleration direction, the cyclist’s initial velocity rounded to tenths, and explicit vector directions. The penny problem now uses the class-source summary’s 1.10 s total fall and asks for impact speed and roof height. It replaces the old unsupported 1.85 s impact-time premise and duplicated velocity part.

## Equation renderer

The production style that absolutely positioned every equation token is now scoped to the original equation stage. Substitution tokens remain in normal mathematical flow, with operators and parentheses preserved during movement. Negative numbers are parenthesized, including before squaring and inside roots. The production-browser checks exercise average-velocity fractions, negative gravitational acceleration, roots, rearrangement and substitution. Clue matching respects word/numeric boundaries and sentence punctuation, so dropped is selected rather than a zero inside 2.0.

## Graphs

Ten supported question graphs and eleven motion diagrams are available. Audited plots include a rocket’s quadratic position, the cyclist’s actual 2.0 m/s initial velocity, the elevator’s 0–2–14–18 s velocity stages and 15 m area, the golf ball’s parabolic throw and 4 s turning point, negative steady velocity, braking area, and bouncing motion. The bouncing problem uses its explicit down-positive convention; the position curve stays continuous while contact velocity changes are drawn as separate segments because contact duration was not supplied. Original textbook/review graphs with missing coordinates are not invented. Every plotted axis includes a quantity and unit, correctly signed ranges and a scale.

## Notes

Six note references are organized as notes, with no assignments, generated lessons, questions, reading status or completion. Four partial faithful transcriptions are provisioned only in the owner’s private runtime archive: motion definitions, algebra refresher, graphing activity and significant-figure reminder. They preserve the captured wording/equations/order; unresolved blanks, radical terms and missing diagrams/layout are listed. Full original acceleration and free-fall notes are unavailable. These are **partial transcriptions, not perfect completed copies**. Original photographs/OCR, names, grades and completed student reports are excluded from Git, public pages, browser offline caches and Docker build context.

## Labs and documents

Labs include formal report instructions/resources, the formal uniform-motion toy-car investigation, the informal sprint position/time/velocity lab, and the inclined-cart ticker-tape lab. Each has an evidence-first ChatGPT prompt: gather the student’s own data/pictures, observations, procedure, instructions/rubric, uncertainties and relevant group information; wait before drafting; then work through only the required sections. No fabricated experimental results or completed student report is supplied.

The main formal template is an editable Word DOCX with Times New Roman 12 pt, single spacing, Letter paper, 1-inch margins, centred title, lower-right identifying fields, an explicitly blank reverse, Wadson’s report headings and Literature Cited on a separate final page. All five rendered pages were visually inspected. The existing six-page PDF has 15 canonical AcroForm fields with 15 widget annotations and Times-Roman 12 pt default appearances. The optional legacy HTML editing URL remains available, but Word is the primary Labs download. The teacher’s example is linked to the class resource instead of copying a completed student report.

Ticker analysis uses the captured eleven legible time/position pairs privately or a student’s supplied table. It converts actual lengths, calculates each interval displacement and velocity, assigns midpoint times, plots real points and fits velocity against time. It distinguishes fitted acceleration from first-to-last average velocity. It never inserts an unrecorded (0,0). Faint later ticker readings and uncertainty were not legible. The review package’s different 0.050 s-per-dot tape image is missing and is requested explicitly; it is not replaced with the lab tape.

## Backend and owner access

The owner administrator is Jovan; the requested password is provisioned privately as an Argon2id hash, with no plaintext credential committed or stored in the persistent deployment environment. The original private class archive stays in the backend data volume. Public API responses are not cached; the hostname adapter retains `no-store` when forwarding private source responses.

Live QA exposed an existing sign-out race: a remembered account could render before reconnect had obtained its server CSRF token. Sign-out now confirms the current cookie session first, and stale reconnect responses cannot restore the account after it signs out. Desktop and phone regression checks deliberately delay the original session response through logout and confirm that both the session and account hint remain cleared.
