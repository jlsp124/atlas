# Chemistry 0.1.10

Chemistry opens Assignments, Notes and Labs at course and unit level. Real Hebden
questions receive short paper-first explanations. Dimensional analysis, electron
configurations, ion changes and Lewis structures receive the visual help they
need. The shared Atlas shell and existing assignment/question IDs remain intact.
Formal independent hand-ins remain metadata only.

class-source route supports owner-only note and observation copies without
placing them in the static build or public repository.

water), Flinn Scientific's _Foiled Again_ demonstration (aluminium/copper(II)
chloride), ACS's related metal displacement lesson, NIST's lauric-acid phase data,
and OpenStax's phase/change explanations. Direct links appear in each lab.

record does not identify a gas. No measured value is generated. Heating/cooling
graphs start empty and plot only entered measurements.

Lab dates are unconfirmed because no current dated lab calendar is supplied.
They are retained as undated material. The previously confirmed October 16 test
