# Atlas development and intake

For "Put this in Atlas" or "Update atlas", read `docs/INTAKE.md` first and the
canonical `02 Projects/Atlas Intake.md` in the private `jlsp124/obsidian-vaults`
repository. The October 8, 2026 subject-specific product brief supersedes conflicting
earlier UX instructions. See `docs/SUBJECT_MODELS.md` for the current product
contract and `docs/V3.md` for the preserved shared foundation.

Schoolwork is the interface: course → unit → material set → actual notes,
worksheet, lab or reference → the smallest helpful explanation → the same work.
Preserve the neutral themes, accents and sidebar. Do not introduce green.
Units open real material directly. There is no primary Learn/Classwork fork or
mandatory parallel curriculum. Keep assignment and checkpoint IDs stable.

Search the private registry and permitted vault before creating a source.
Record capture order and metadata before copying or grouping. Keep raw files,
OCR, completed student labs, marked work, names, grades and teacher comments
outside this public repository and Docker/build contexts. Never read or modify
`06 My Notes`. Publish reviewed original derivatives and resource links only.

Formal Chemistry hand-ins are metadata only. Regular assigned textbook work is
Hebden; Glencoe lab sources retain a separate identity. Use the exact supplied
teacher-note assignment ranges and conventions; record uncertain dates.

`npm run atlas:update` inspects; `--apply` accepts reviewed derivatives. A fetch
does not authorize turning raw text into questions. Run the complete checks
and verify the exact deployed commit after authorized publication.
